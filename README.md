# Portfolio Website

My personal portfolio website showcasing eperience, and journey as a full-stack web developer.

The website serves as a central place to learn more about me, view my resume, and get in touch.

## 🛠️ Built With

- Entirely vanilla HTML/CSS/JavaScript

## 🚀 Running Locally

Clone the repository or download the ZIP:

```bash
git clone https://github.com/yourusername/portfolio.git
```
Simply open the index.html file.

Or open the project with your favorite IDE and run the project with any local development server extension you have.
